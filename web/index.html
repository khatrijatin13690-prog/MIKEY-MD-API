Available endpoints.

GET/api/healthService and database status
GET/api/statsAggregate usage statistics
POST/api/messages/textSend a WhatsApp text message · API key required
GET/webhookMeta webhook verification
POST/webhookReceive WhatsApp events
GET/api/docsMachine-readable API documentation
Send a text message
curl -X POST "https://YOUR-RAILWAY-DOMAIN/api/messages/text" \
  -H "Content-Type: application/json" \
  -H "x-api-key: YOUR_PRIVATE_API_KEY" \
  -d '{
    "to": "919876543210",
    "text": "Hello from MIKEY MD API"
  }'
GETTING STARTED

Deploy in three steps.

01

Deploy the backend

Push the api folder to GitHub and deploy it on Railway. Add a PostgreSQL service.

02

Connect Meta

Configure your WhatsApp Business phone number, access token, app secret and webhook URL.

03

Publish this website

Deploy the web folder on Vercel and set the Railway API URL in app.js.

This project uses the official WhatsApp Business Cloud API. It does not provide WhatsApp Web QR pairing. Follow WhatsApp's messaging policies and consent requirements.
